send the minimum approved context rather than inherited conversation history.

- Soft duration and token budgets / measurement availability / checkpoint:
- Dependency owner / unblock condition / owner escalation trigger:
- Raw telemetry root outside Git / event IDs / sanitized evaluation destination:
- Commit authority / exact branch / integration owner:
- Required output and handoff destination:

Record assignment/start and wait/completion/abort/retry events following
[monitoring](../monitoring.md). Apply the three-attempt verification and two-round
review limits from the [runbook](../agents/README.md). Role instructions are
behavioral constraints, not sandbox enforcement. Escalate authorization changes;
continue routine scoped fixes and meaningful local commits autonomously.
